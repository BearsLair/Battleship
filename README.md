# Battleship

The two-player (or computer) game Battleship, done with Javascript in the browser.

# IMPORTANT

Jest unit-testing not fully compatible with javascript ES6 module syntax.
Change type in package.json to "commonjs" to use tests.
Change it back to "module" to run the game in browser.

# AI-Driven Development

Done for ship placement logic (placing ship starting locations, ensuring ships stay on board, with no ships overlapping others)
Done for for CPU ship placement logic (random placing of ships, ships stay on board, no overlapping)
